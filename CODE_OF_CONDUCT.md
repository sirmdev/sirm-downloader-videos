# Código de Conduta

Este projeto adota o [Contributor Covenant 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: seja respeitoso, acolha opiniões diferentes, critique ideias e não pessoas, e não tolere assédio. O mantenedor pode remover comentários, commits, issues e PRs que violem estas regras.

Para relatar um comportamento inadequado, fale com o mantenedor pelo perfil do GitHub [@sirmdev](https://github.com/sirmdev).
